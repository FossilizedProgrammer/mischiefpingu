# پینگوی شیطون (MischiefPingu)

**کلاینت چند-هسته‌ای — سایفون • اتر • تور • اس‌اس‌تی‌پی**

یک رابط گرافیکی Flutter برای دسکتاپ (لینوکس و ویندوز) که چند هستهٔ عبور از سانسور را در یک رابط تمیز و یکپارچه جمع می‌کند.

🔗 **گیت‌هاب:** [github.com/FossilizedProgrammer/mischiefpingu](https://github.com/FossilizedProgrammer/mischiefpingu)
📬 **ارتباط با توسعه‌دهنده (ایکس):** [@tenblockperhour](https://x.com/tenblockperhour)

> **اطلاعیهٔ حقوقی دربارهٔ سایفون:**
> این یک **کلاینت غیررسمی سایفون** است و **هیچ‌گونه وابستگی یا تأییدی از سوی شرکت Psiphon Inc. ندارد.** نام «سایفون / Psiphon» و هستهٔ رسمی سایفون، متعلق به شرکت Psiphon Inc. است.

## ✨ امکانات

### 🔌 چهار هستهٔ قابل اتصال
- **سایفون** — باینری رسمی psiphon-tunnel-core به‌همراه فورک **شیر و خورشید (SunAndLion)** برای فرانتینگ CDN.
- **اتر** — پروتکل‌های MASQUE / MIM / WireGuard / Gool با اسکن خودکار اندپوینت.
- **تور** — یکپارچه‌سازی expert-bundle با پلاگین‌های obfs4، meek، snowflake، webtunnel و conjure.
- **اس‌اس‌تی‌پی** — کلاینت پروکسی SSTP، توسعه‌داده‌شده توسط سازندهٔ همین برنامه.

### 🧠 حالت‌های هوشمند اتصال (سایفون)
1. **فرانتینگ (CDN)** — فورک شیر و خورشید با تنظیم `FRONTED-MEEK-CDN-OSSH`. بهترین برای سانسور سنگین.
2. **آپ‌استریم اتر** — هستهٔ رسمی سایفون از طریق SOCKS5 اتر.
3. **Conduit (WebRTC Inproxy)** — رله‌های غیرمتمرکز همتا.
4. **مستقیم** — هستهٔ رسمی سایفون بدون فرانتینگ.

### 🔗 تونل‌های زنجیره‌ای
- تور از طریق اتر / سایفون / اس‌اس‌تی‌پی
- اس‌اس‌تی‌پی از طریق اتر / سایفون / تور
- سایفون از طریق اتر / تور / اس‌اس‌تی‌پی / پروکسی دستی

### 🎛️ پروفایل‌های اتر — جستجوی خودکار مسیر
اتر نیازی به دست‌کاری تنظیمات پیچیده توسط کاربر ندارد. چند پروفایل آماده دارد و **خودش به‌ترتیب آن‌ها را امتحان می‌کند تا بهترین مسیر کارکننده را پیدا کند**:

- **تطبیقی** — تعادل سرعت و پوشش؛ MASQUE/HTTP-3 → MASQUE/HTTP-2 → WireGuard → Gool.
- **سیگنال ناپایدار** — برای دیتای موبایل ناپایدار؛ MIM/HTTP-3 را هم امتحان می‌کند و از `--noize balanced` استفاده می‌کند.
- **شبکه محدود** — برای وای‌فای محدود یا فیلتر سنگین؛ fragment + masque-in-masque و `--noize gfw`.
- **دستی** — کنترل کامل برای کاربران حرفه‌ای.

آخرین پروتکل و اندپوینت موفق به خاطر سپرده می‌شود و در اجرای بعدی اول از همه امتحان می‌شود.

### 🛰️ اسکنر آی‌پی CDN
- پیش‌تنظیم‌های آماده: Akamai، Cloudflare، Fastly، Google CDN، Amazon CloudFront، Microsoft Azure.
- گسترش CIDR / بازه / آی‌پی تکی (تا ۲۰٬۰۰۰ ورودی).
- بررسی موازی TLS handshake با امتیازدهی تأخیر و پایداری.
- اعمال Top 5 / Top 20 روی تنظیمات فرانتینگ.

### 🌐 دریافت‌کنندهٔ سرورهای VPN Gate
- استخراج از **vpngate.net** (مستقیم یا از طریق هر پروکسی فعال).
- بازخوانی خودکار هر ۱۵ دقیقه.
- بررسی سلامت موازی با TCP + TLS ClientHello.
- کپی نتایج به‌صورت لیست ساده یا CSV با جزئیات.

### 🛠️ آپدیت هسته‌ها
آپدیت‌کنندهٔ داخلی برای همهٔ باینری‌ها (اتر، تور، سایفون، شیر و خورشید، SSTP). آپدیت‌ها ذخیره و در استارت بعدی اعمال می‌شوند.

### 🌍 چندزبانه
ترجمهٔ کامل رابط کاربری به **انگلیسی**، **فارسی** و **روسی** با تغییر آنی.

### 🎨 امکانات دیگر
- ۶ تم رنگی با حالت روشن/تیرهٔ خودکار.
- ذخیرهٔ تنظیمات با SharedPreferences.
- پشتیبانی از اشتراک در شبکهٔ محلی برای همهٔ هسته‌ها.
- اتصال مجدد خودکار برای هر هسته.
- کنسول لاگ زنده با کپی / پاک‌سازی.
- Watchdog تونل با بازیابی خودکار.
- پنگوئن که به رویدادهای اتصال واکنش نشان می‌دهد.

## 🙏 قدردانی

این پروژه بدون تلاش دیگران وجود نداشت. سپاس صمیمانه از:

- **اتر (Aether)** — [CluvexStudio/Aether](https://github.com/CluvexStudio/Aether/releases#release-v2.0.0). هستهٔ اتر موتور همهٔ ترنسپورت‌های غیر از سایفون، تور و اس‌اس‌تی‌پی در این برنامه است. تمام اعتبار هستهٔ اتر از سازندهٔ آن است.
- **فورک شیر و خورشید (SunAndLion) سایفون** — [shirokhorshid/psiphon-tunnel-core](https://github.com/shirokhorshid/psiphon-tunnel-core). حالت فرانتینگ / CDN در این برنامه به‌طور کامل بر این فورک استوار است. **توسعهٔ این هسته بر عهدهٔ سازندهٔ شیر و خورشید است** — سازندهٔ این برنامه فقط باینری کامپایل‌شده را در مخزن خودش بازنشر کرده، چون مخزن اصلی باینری آماده نداشت.
- **سایفون رسمی** — [Psiphon-Labs/psiphon-tunnel-core-binaries](https://github.com/Psiphon-Labs/psiphon-tunnel-core-binaries). هستهٔ رسمی سایفون برای حالت‌های مستقیم، آپ‌استریم اتر، Conduit، آپ‌استریم تور و آپ‌استریم SSTP استفاده می‌شود.
- **پروژهٔ تور (Tor Project)** — برای باندل تخصصی تور و پلاگین‌های ترنسپورت.
- **فلاتر (Flutter)** — [flutter.dev](https://flutter.dev). تمام این رابط گرافیکی روی فلاتر ساخته شده است.
- **FossilizedProgrammer/sstp-proxy** — [github.com/FossilizedProgrammer/sstp-proxy](https://github.com/FossilizedProgrammer/sstp-proxy). **کلاینت پروکسی SSTP این برنامه توسط سازندهٔ پینگوی شیطون توسعه داده شده است.** پروتکل SSTP پیش‌تر توسط پروژه‌های دیگر به‌صورت VPN سیستم‌واید استفاده می‌شد؛ پیاده‌سازی sstp-proxy این پروتکل را به‌صورت **پروکسی محلی** در اختیار می‌گذارد، و همین چیزی است که زنجیره‌سازی تونل‌ها را ممکن می‌کند.

### نکته‌ای دربارهٔ باینری شیر و خورشید

فایل `psiphon-tunnel-core-sunandlion` داخل برنامه، نام محلی انتخاب‌شده برای فورک شیر و خورشید است. این نام، نام اصلی پروژه نیست. تمام توسعه، نگهداری و رفع اشکال آن هسته در [shirokhorshid/psiphon-tunnel-core](https://github.com/shirokhorshid/psiphon-tunnel-core) انجام می‌شود. این مخزن فقط باینری کامپایل‌شده را آینه می‌کند تا برنامه بتواند از طریق آپدیتر داخلی خودش آن را دانلود کند.
