# 🐧 پینگوی شیطون (MischiefPingu)

<div align="center">

**کلاینت چند-هسته‌ای — سایفون • اتر • تور • اس‌اس‌تی‌پی • وایرگارد • وی‌پی‌ان فایرفاکس • لنترن • گِف • ان‌پی‌وی تانل (napsternetV)**

## ⚠️ اطلاعیهٔ حقوقی دربارهٔ سایفون

> این یک کلاینت **غیررسمی** سایفون است و هیچ‌گونه وابستگی یا تأییدی از سوی شرکت Psiphon Inc. ندارد.  
> نام «سایفون / Psiphon» و هستهٔ رسمی سایفون، متعلق به شرکت Psiphon Inc. است.

---

## ⚠️ اطلاعیهٔ حقوقی دربارهٔ وی‌پی‌ان فایرفاکس

> این یک کلاینت **غیررسمی** وی‌پی‌ان فایرفاکس است و هیچ‌گونه وابستگی یا تأییدی از سوی فایرفاکس (موزیلا) ندارد.  
> نام‌های «Firefox» و «Mozilla» متعلق به بنیاد Mozilla هستند. این پروژه توسط موزیلا حمایت، پشتیبانی یا تأیید نمی‌شود و یک محصول رسمی موزیلا نیست.

## ✨ امکانات

### 🔌 هسته‌های قابل اتصال

| هسته | توضیحات |
|------|---------|
| **سایفون** | باینری رسمی `psiphon-tunnel-core` به‌همراه فورک شیر و خورشید (SunAndLion) برای فرانتینگ CDN |
| **اتر** | پروتکل‌های MASQUE / MIM / WireGuard / Gool با اسکن خودکار اندپوینت |
| **تور** | یکپارچه‌سازی expert-bundle — ترنسپورت‌های obfs4، meek، webtunnel، scramblesuit و snowflake از طریق باینری `lyrebird` و همچنین conjure (`conjure-client`) |
| **اس‌اس‌تی‌پی** | کلاینت پروکسی SSTP، توسعه‌داده‌شده توسط سازندهٔ همین برنامه |
| **وایرگارد** | کلاینت userspace مبتنی بر wireproxy با دو هسته: **Standard** (wireguard-go) و **AmneziaWG** (نسخهٔ مبهم‌سازی‌شده برای سانسور سنگین) |
| **وی‌پی‌ان فایرفاکس** | کلاینت داخلی **IP Protection** فایرفاکس (`ffvpn`، مبتنی بر Mozilla VPN) — با حساب Firefox Account وارد می‌شود و یک پروکسی محلی SOCKS5/HTTP در اختیار می‌گذارد |
| **لنترن** | دو موتور: **Radiance** (`lantern-radiance`، موتور کلاینت رسمی لنترن ۱۰ — پیش‌فرض) و **Classic** (باینری headless `lantern`). هر دو پروکسی محلی SOCKS5/HTTP می‌دهند و هر دو آپدیت‌کنندهٔ داخلی را دارند |
| **گِف** | کلاینت غیررسمی **Geph 5** (`geph5-proxy`) — ساخت/ورود حساب، انتخاب کشور خروجی رایگان/پرمیوم، پروکسی محلی SOCKS5/HTTP |
| **ان‌پی‌وی تانل** | کلاینت `npv-go` — ساختهٔ خودِ نویسندهٔ این برنامه. کانفیگ‌های export‌شده از اپ اندرویدی **NPV Tunnel V2raySSH** (فایل‌های `.npvs`) را رمزگشایی می‌کند، همهٔ آن‌ها را با یک درخواست واقعی می‌سنجد و روی سریع‌ترین کانفیگ زنده listener باز می‌کند؛ پروکسی محلی SOCKS5/HTTP. در تنظیمات، همهٔ کانفیگ‌های فایل با ترتیب سرعت اندازه‌گیری‌شده و دلیل خطای مرده‌ها نمایش داده می‌شود |

**ویژگی‌های عمومی:**  
پورت SOCKS محلی در همهٔ هسته‌ها؛ Share-on-LAN در همهٔ هسته‌ها به‌جز وی‌پی‌ان فایرفاکس و لنترن؛ اتصال مجدد خودکار در سایفون، تور، اس‌اس‌تی‌پی، اتر، وایرگارد و ان‌پی‌وی؛ و پیست کردن کانفیگ، URI یا لیست بریج هر جا که هسته آن را می‌پذیرد (`.conf` / `wireguard://` / `vpn://` برای وایرگارد، `.npvs` برای ان‌پی‌وی، بریج‌ها برای تور، و لیست سرور/CDN برای اس‌اس‌تی‌پی و سایفون).

| **اس‌اس‌تی‌پی** | اتر · سایفون · تور · وایرگارد · وی‌پی‌ان فایرفاکس · لنترن · گِف · ان‌پی‌وی · پروکسی دستی |
| **وی‌پی‌ان فایرفاکس** | اتر · سایفون · تور · اس‌اس‌تی‌پی · وایرگارد · لنترن · گِف · ان‌پی‌وی · پروکسی دستی |
| **لنترن** | اتر · سایفون · تور · اس‌اس‌تی‌پی · وایرگارد · وی‌پی‌ان فایرفاکس · گِف · ان‌پی‌وی · پروکسی دستی |

### 🎛️ پروفایل‌های اتر — جستجوی خودکار مسیر

اتر نیازی به دست‌کاری تنظیمات پیچیده توسط کاربر ندارد. چند پروفایل آماده دارد و خودش به‌ترتیب آن‌ها را امتحان می‌کند تا بهترین مسیر کارکننده را پیدا کند:

| پروفایل | توضیحات |
|---------|---------|
| **تطبیقی** | تعادل سرعت و پوشش؛ MASQUE/HTTP-2 → MASQUE/HTTP-3 → MIM/HTTP-2 → MIM/HTTP-3 → Gool → WireGuard، اسکن `balanced` و بدون مبهم‌سازی اضافه (همان اولین تلاش کلاینت اندروید) |
| **سیگنال ناپایدار** | برای دیتای موبایل ناپایدار؛ MIM/HTTP-3 را هم امتحان می‌کند و از `--noize balanced` استفاده می‌کند |
| **شبکه محدود** | برای وای‌فای محدود یا فیلتر سنگین؛ fragment + masque-in-masque و `--noize gfw` |
| **دستی** | کنترل کامل برای کاربران حرفه‌ای |

> 💡 آخرین پروتکل و اندپوینت موفق به خاطر سپرده می‌شود و در اجرای بعدی اول از همه امتحان می‌شود.

### 🛰️ اسکنر آی‌پی CDN

- **پیش‌تنظیم‌های آماده:** Akamai، Cloudflare، Fastly، Google CDN، Amazon CloudFront، Microsoft Azure (به‌همراه لیست شخصی خودتان)
- **گسترش CIDR / بازه / آی‌پی تکی** در سه حالت اسکن — Quick (۲۰۰ آی‌پی)، Balanced (۲٬۰۰۰) و Deep (گسترش کامل، تا ۲۰٬۰۰۰)
- **بررسی موازی TLS handshake** با امتیازدهی تأخیر و پایداری
- **اسناوت SNI** — میزبان‌های فرانتینگی را پیدا می‌کند که در شبکهٔ شما مسدود نیستند
- **اعمال Top 5 / Top 20** روی تنظیمات فرانتینگ

---

### 📡 دریافت‌کنندهٔ سرورهای VPN Gate

- استخراج از `vpngate.net` (مستقیم یا از طریق هر پروکسی فعال)
- بازخوانی خودکار (اختیاری) هر ۱۵ دقیقه
- بررسی سلامت موازی با TCP + TLS ClientHello
- کپی نتایج به‌صورت لیست ساده یا CSV با جزئیات

---

### 🛠️ آپدیت هسته‌ها

آپدیت‌کنندهٔ داخلی برای باینری‌های اتر، تور، سایفون، شیر و خورشید، SSTP، wireproxy (هم هستهٔ Standard و هم AmneziaWG)، وی‌پی‌ان فایرفاکس، لنترن و ان‌پی‌وی تانل — هستهٔ گِف باندل شده ولی آپدیت‌کننده ندارد. آپدیت‌ها ذخیره و در استارت بعدی اعمال می‌شوند.

### 🎨 امکانات دیگر

- ۶ تم رنگی با حالت روشن/تیرهٔ خودکار
- ذخیرهٔ تنظیمات با SharedPreferences
- اشتراک در شبکهٔ محلی روی همهٔ هسته‌هایی که پروکسی محلی می‌سازند — سایفون، تور، اس‌اس‌تی‌پی، اتر، وایرگارد، گِف و ان‌پی‌وی (وی‌پی‌ان فایرفاکس و لنترن فقط localhost)
- اتصال مجدد خودکار برای سایفون، تور، اس‌اس‌تی‌پی، اتر، وایرگارد و ان‌پی‌وی
- کنسول لاگ زنده با قابلیت کپی / پاک‌سازی
- Watchdog تونل با بازیابی خودکار
- **سلامت تونل** — تأخیر، پکت‌لاس، جیتر، آپ‌تایم و شمارش reconnect برای هر تونل درحال‌اجرا
- **کیفیت اینترنت** — سنجش پس‌زمینهٔ لین با رتبهٔ کیفی و تاریخچه
- **اسکنر بریج** — گرفتن و تست تأخیر بریج‌های obfs4، webtunnel، snowflake، meek و conjure
- **گزارش عیب‌یابی** — کپی/ذخیرهٔ وضعیت برنامه با حذف خودکار اطلاعات حساس
- **آپدیت برنامه** — بررسی آخرین ریلیز و دانلود آن از طریق تونل فعال در صورت لزوم
- پنگوئنی که به رویدادهای اتصال واکنش نشان می‌دهد! 🐧

## 🚀 نصب و اجرا

### 🐧 لینوکس — پیش‌نیازها

قبل از اجرا یا بیلد روی لینوکس، پکیج‌های توسعهٔ GStreamer را نصب کنید:

**sudo apt install libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev**

### 📦 بیلد

ابتدا دستور زیر را اجرا کنید:

**flutter pub get**

سپس برای لینوکس:

**flutter build linux --release --no-tree-shake-icons**

یا برای ویندوز:

**flutter build windows --release --no-tree-shake-icons**

روی لینوکس می‌توانی به‌جای این دو دستور **./tool/build-linux.sh** را اجرا کنی: همان بیلد release را می‌گیرد و پوشهٔ `bundled/linux/` را هم داخل باندل کپی می‌کند، پس **`build/linux/x64/release/bundle` تنها خروجی قابل اجراست**. هرچه زیر `build/linux/x64/debug/` می‌بینی خروجی `flutter run` است — هیچ هسته‌ای کنارش کپی نشده و رلیز محسوب نمی‌شود.

| [**پروژهٔ تور**](https://www.torproject.org/) | برای باندل تخصصی تور و پلاگین‌های ترنسپورت |

| [**AmneziaWG**](https://github.com/amnezia-vpn/amneziawg-go) | فورک مبهم‌سازی‌شدهٔ WireGuard برای مقاومت در برابر DPI |
| [**فلاتر (Flutter)**](https://flutter.dev/) | تمام این رابط گرافیکی روی فلاتر ساخته شده است |
| [**sstp-proxy**](https://github.com/FossilizedProgrammer/sstp-proxy) | کلاینت پروکسی SSTP این برنامه توسط سازندهٔ پینگوی شیطون توسعه داده شده است. این پیاده‌سازی پروتکل را به‌صورت پروکسی محلی در اختیار می‌گذارد و زنجیره‌سازی تونل‌ها را ممکن می‌کند |
| [**firefox-vpn-go**](https://github.com/FossilizedProgrammer/firefox-vpn-go) | هستهٔ وی‌پی‌ان فایرفاکس این برنامه — کلاینت Go مستقل برای وی‌پی‌ان داخلی IP Protection فایرفاکس (Mozilla VPN) که به‌صورت باینری آمادهٔ release منتشر می‌شود |

| [**npv-go**](https://github.com/FossilizedProgrammer/npv-go) | هستهٔ NPV این برنامه، ساختهٔ خودِ نویسندهٔ پینگوی شیطون — فایل‌های `.npvs` خروجیِ اپ اندرویدی NPV Tunnel (V2raySSH) را رمزگشایی می‌کند و با xray-core به‌صورت درون‌پروسه اجرا می‌کند. به‌صورت باینری آماده در Releases منتشر می‌شود و بخش «آپدیت هسته‌ها» همان را نصب می‌کند |

### 📝 نکته‌ای دربارهٔ باینری شیر و خورشید

> فایل `psiphon-tunnel-core-sunandlion` داخل برنامه، نام محلی انتخاب‌شده برای فورک شیر و خورشید است. این نام، نام اصلی پروژه نیست. تمام توسعه، نگهداری و رفع اشکال آن هسته در [`shirokhorshid/psiphon-tunnel-core`](https://github.com/shirokhorshid/psiphon-tunnel-core) انجام می‌شود. این مخزن فقط باینری کامپایل‌شده را آینه می‌کند تا برنامه بتواند از طریق آپدیتر داخلی خودش آن را دانلود کند.
